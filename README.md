# Want List

A tiny wishlist app that ranks the things you want to buy by asking you one simple question: **which do you want more?**

Instead of scoring items by hand, you compare them two at a time. Each new item is placed with a few quick head-to-head picks, and every item gets a score out of 10 based on where it lands.

## Features

- Add items with a price, category, link, and a note on why you want them
- Rank by comparison: pick between two items until the new one finds its spot
- Scores out of 10, grouped into "Really want it," "Would be nice," and "Just curious"
- Filter by category and see the total cost of your list
- Mark items as bought to move them to a "Got it" tab
- Export and import backups as JSON
- Keyboard shortcuts: ← and → to choose while comparing
- Light and dark mode

## Getting started

No install or build step. It's a single HTML file.

1. Download `Want List.html`
2. Open it in your browser

Your list is saved in your browser's local storage, so it stays private on your machine. Use **Export backup** now and then to keep a copy.

## Built with

Plain HTML, CSS, and JavaScript. No frameworks or dependencies.
